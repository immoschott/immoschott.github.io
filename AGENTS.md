# Repository rules

## Research-project classification

- Keep `cv_immo.tex` and `index.html` consistent about which projects are working papers and which are work in progress.
- A **working paper** is an advanced project with material that is ready to share publicly, such as a working-paper draft or a set of slides. Publicly linked project material normally means the project belongs in this category.
- **Work in progress** is a project for which an internal draft or slides may exist, but the material is not yet ready for public dissemination.
- When a project's status changes, update both the CV and the website in the same change. Add or remove public links as appropriate for the new classification.
- Accepted and published papers belong in the publications/accepted-manuscripts section rather than either of these categories.
